## 🚀 Быстрый старт

### 1. Открыть локально
Просто откройте `index.html` в браузере.

### 2. Загрузить на GitHub Pages

```bash
# Инициализация Git
git init
git add .
git commit -m "Initial commit: сайт Фатимы"
git branch -M main

# Добавить remote
git remote add origin https://github.com/c1utchw/darckmagicfatima.git

# Отправить на GitHub
git push -u origin main
```

### 3. Настроить GitHub Pages
1. Зайдите в репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. Выберите: **Source** = Deploy from branch
4. Branch: **main**, Folder: **/** (root)
5. Нажмите **Save**

Сайт будет доступен по адресу:
```
https://c1utchw.github.io/darckmagicfatima/
```

## ⚙️ Что нужно заменить

### 1. Номер телефона
Найдите во всех файлах и замените:
- `+999999999999999` → реальный номер
- `999999999999999` → реальный номер (для ссылок)

**Файлы для правки:**
- `index.html` (несколько мест)
- `js/main.js` (функция updatePhoneNumber)

### 2. Фото Фатимы
1. Подготовьте фото (рекомендуемый размер: 300×420 px)
2. Сохраните в папку `images/` как `hero-photo.jpg`
3. В `index.html` замените:
```html
<!-- Было -->
<div class="hero-image-placeholder">...</div>

<!-- Стало -->
<img src="images/hero-photo.jpg" alt="Фатима" class="hero-photo">
```

### 3. YouTube видео
1. Найдите нужное видео на YouTube
2. Скопируйте ID видео (после `v=` в URL)
3. В `index.html` замените:
```html
<!-- Было -->
<div id="youtube-player" data-video-id="VIDEO_ID"></div>

<!-- Стало (пример) -->
<div id="youtube-player" data-video-id="dQw4w9WgXcQ"></div>
```

### 4. Сертификаты
1. Подготовьте изображения сертификатов
2. Сохраните в `images/certificate-1.jpg`, `certificate-2.jpg` и т.д.
3. Они автоматически появятся вместо плейсхолдеров

### 5. Ссылки на соцсети
В подвале замените:
- `https://t.me/username` → реальный Telegram
- WhatsApp ссылки уже настроены

### 6. SEO данные
В `index.html` и `sitemap.xml` замените:
- `c1utchw` → ваш логин GitHub
- Обновите `lastmod` даты

## 🐛 Решение проблем

### Видео не воспроизводится
- Проверьте что `VIDEO_ID` заменён на реальный
- Некоторые браузеры блокируют автоплей со звуком — появится кнопка Play

### Картинки не отображаются
- Проверьте пути к файлам
- Убедитесь что изображения в папке `images/`

### Стили не работают
- Проверьте что CSS файлы в папке `css/`
- Очистите кэш браузера (Ctrl+F5)
